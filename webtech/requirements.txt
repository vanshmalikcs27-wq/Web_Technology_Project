# Webbio - Complete Requirements List
# Updated: April 2026

## SYSTEM REQUIREMENTS

### Operating System
- Windows 10+ / macOS 10.14+ / Linux (Ubuntu 18.04+)

### Runtime & Package Manager
- Node.js >= 16.0.0 (Download: https://nodejs.org/)
- npm >= 8.0.0 (Comes with Node.js)

### Database
- MongoDB Atlas Account (Free tier available)
  - Sign up: https://www.mongodb.com/cloud/atlas
  - Free tier: 0.5GB storage, shared cluster

### Browser Support (Frontend)
- Chrome/Edge 90+
- Firefox 88+
- Safari 14+

## BACKEND DEPENDENCIES (Node.js)

### Web Framework & Core
express@^4.18.2                 # Web server framework
mongoose@^7.0.0                # MongoDB object mapper and ODM

### Authentication & Security
bcrypt@^5.1.0                  # Password hashing and verification
jsonwebtoken@^9.0.2            # JWT token generation and validation

### Middleware & Utilities
cors@^2.8.5                    # Cross-Origin Resource Sharing (CORS)
body-parser@^1.20.2            # Request body parsing (JSON and URL-encoded)
dotenv@^16.3.1                 # Environment variables management

### Development Dependencies (Optional but Recommended)
nodemon@^3.0.0                 # Auto-restart server on file changes (dev only)

## INSTALLATION INSTRUCTIONS

### 1. Install Node.js
- Download: https://nodejs.org/
- Choose LTS version (v18+ or v20+)
- Verify installation:
  ```
  node --version
  npm --version
  ```

### 2. Install Backend Dependencies
```bash
cd backend
npm install
```

This will automatically install all packages listed in backend/package.json:
- express
- mongoose
- bcrypt
- jsonwebtoken
- cors
- body-parser
- dotenv

### 3. Install Development Tools (Optional)
```bash
npm install --save-dev nodemon
```

## ENVIRONMENT REQUIREMENTS

### MongoDB Atlas
- Account Setup: https://www.mongodb.com/cloud/atlas
- Free Tier: "M0" Shared Cluster (0.5GB)
- Connection Method: Node.js Driver
- Network Access: Configure IP whitelist
- Database User: Create username/password

### Environment Variables (.env file)
Required in `backend/.env`:
```
MONGODB_URI=mongodb+srv://username:password@cluster-name.mongodb.net/webbio?retryWrites=true&w=majority
PORT=5000
NODE_ENV=development
JWT_SECRET=your_super_secret_key_here_minimum_32_chars
FRONTEND_URL=http://localhost:3000
```

## INSTALLATION COMMANDS

### Quick Install
```bash
# Navigate to backend
cd backend

# Copy environment template
cp .env.example .env

# Install all dependencies
npm install

# Start development server
npm run dev
```

### Full Setup (Step-by-Step)
```bash
# 1. Clone/navigate to project
cd webtech/backend

# 2. Create .env file
cp .env.example .env

# 3. Edit .env with your MongoDB credentials
# (Use your MongoDB Atlas connection string)

# 4. Install dependencies
npm install

# 5. Install optional dev tools
npm install --save-dev nodemon

# 6. Start server
npm run dev        # Development (auto-reload)
# or
npm start          # Production

# 7. Verify server is running
curl http://localhost:5000/api/health
```

## TROUBLESHOOTING

### Node.js Not Found
```
Command: npm install
Error: 'node' is not recognized
Solution: Install Node.js from https://nodejs.org/
```

### Dependencies Installation Fails
```
Error: npm ERR! code ERESOLVE
Solution: 
  npm install --legacy-peer-deps
```

### MongoDB Connection Failed
```
Error: MongoServerError: authentication failed
Solution:
  - Verify MONGODB_URI in .env
  - Check username/password
  - Ensure IP is whitelisted
```

### Port 5000 Already in Use
```
Error: listen EADDRINUSE
Solution: 
  - Change PORT in .env (e.g., 5001)
  - Or: npx kill-port 5000
```
